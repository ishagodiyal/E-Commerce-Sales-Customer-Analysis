# E-Commerce Sales & Customer Analysis

## Project Overview
This project focuses on analyzing e-commerce transaction data to understand sales performance, customer purchasing behavior, and business trends using Excel and Power BI.

## Project Objective
- Analyze overall sales performance.
- Identify top-performing customers.
- Explore monthly sales trends.
- Analyze customer purchasing behavior.
- Create an interactive Power BI dashboard.

## Tools Used
- Microsoft Excel
- Power BI

## Data Cleaning
- Removed duplicate records.
- Checked and handled missing values.
- Prepared data for analysis.
- Calculated revenue.

## Analysis Performed
- Total Revenue Analysis
- Order Analysis
- Average Order Value (AOV)
- Customer Analysis
- Top 10 Customers by Revenue
- Monthly Sales Analysis
- Country-wise Sales Analysis

## Key Metrics
- Total Revenue: 8,278,519.42
- Valid Orders: 22,190
- Average Order Value: 373.07
- Customers: 4,372

## Dashboard

### Sales Analysis
Sales performance dashboard showing key metrics and sales trends.

### Customer Analysis
Customer dashboard focusing on customer performance and purchasing behavior.

## Project Outcome
This project helped explore sales data, identify important business metrics, and visualize sales and customer insights using Excel and Power BI.
